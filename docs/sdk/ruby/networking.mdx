## Creation options

Use these keywords with `Sandbox.create`, `Sandbox.connect_or_create`, or `Sandbox.with`. They are not separate Ruby builder methods.

### network

Use `:none` to disable networking, an allowlist hash with both `allowed_hosts` and `allowed_ports`, or a policy hash with any of `default_egress`, `default_ingress`, and `rules`. A hash cannot mix allowlist and policy fields.

<p className="msb-label">Allowlist fields</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>allowed_hosts</code><span className="msb-type">Array&lt;String&gt;</span></div>
    <div className="msb-param-desc">Allowed destination hosts, matched exactly.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>allowed_ports</code><span className="msb-type">Array&lt;Integer&gt;</span></div>
    <div className="msb-param-desc">Allowed destination TCP ports. Both host and port restrictions must match.</div>
  </div>
</div>

<p className="msb-label">Policy fields</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>default_egress</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc"><code>allow</code> or <code>deny</code> for outbound traffic no rule matches. Defaults to <code>deny</code>.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>default_ingress</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc"><code>allow</code> or <code>deny</code> for inbound traffic no rule matches. Defaults to <code>allow</code>, which keeps published ports reachable.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>rules</code><span className="msb-type">Array&lt;Hash&gt;</span></div>
    <div className="msb-param-desc">Ordered rules; the first match wins. Each rule takes the fields below.</div>
  </div>
</div>

<p className="msb-label">Rule fields</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>action</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc">Required. <code>allow</code> or <code>deny</code>.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>direction</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc"><code>egress</code>, <code>ingress</code>, or <code>any</code>. Defaults to <code>egress</code>.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>destination</code><span className="msb-type">String | Symbol | Hash</span></div>
    <div className="msb-param-desc">A <a href="#destination">Destination</a> hash, or shorthand: a group name, an IP address, a CIDR range, a domain, a domain suffix starting with <code>.</code> or <code>suffix=</code>, <code>domain=</code> followed by a domain, or <code>*</code> for any. Defaults to any destination.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>protocol</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc"><code>tcp</code>, <code>udp</code>, <code>icmpv4</code>, or <code>icmpv6</code>. Defaults to every protocol. ICMP rules must be egress-only.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>port</code><span className="msb-type">Integer | String</span></div>
    <div className="msb-param-desc">A single port, such as <code>443</code>, or an inclusive range, such as <code>"8000-9000"</code>. Defaults to every port.</div>
  </div>
</div>

Invalid policy fields raise ArgumentError or TypeError. Invalid IP addresses, CIDR ranges, and domain names raise `NetworkPolicyError`.

DNS lookups are egress too. A name resolves only when a domain rule matches it or a rule such as [`Rule.allow_dns`](#rule-allow_dns) allows the gateway's port 53. DNS rebind protection drops an answer with a private address unless a CIDR or group egress rule without a `port` allows that address.

<Accordion title="Example">

```ruby
sandbox = Microsandbox::Sandbox.create(
  "worker",
  image: "alpine",
  network: { allowed_hosts: ["api.example.com"], allowed_ports: [443] }
)

sandbox = Microsandbox::Sandbox.create(
  "collector-client",
  image: "alpine",
  network: {
    rules: [
      *Microsandbox::Rule.allow_dns,
      { action: :allow, destination: "172.28.0.0/16", protocol: :tcp },
      { action: :allow, destination: ".github.com", protocol: :tcp, port: 443 }
    ]
  }
)
```

</Accordion>

### ports

Publish guest ports on the host. Local-only. Use a hash of `host_port => guest_port` for TCP on `127.0.0.1`, or an array of hashes with the fields below. Unknown fields, an invalid bind address, or an unknown protocol raise ArgumentError.

<p className="msb-label">Fields</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>host_port</code><span className="msb-type">Integer</span></div>
    <div className="msb-param-desc">Host port to listen on.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>guest_port</code><span className="msb-type">Integer</span></div>
    <div className="msb-param-desc">Guest port to forward to.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>bind</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">Host IP address to bind. Defaults to <code>127.0.0.1</code>.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>protocol</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc"><code>tcp</code> or <code>udp</code>. Defaults to <code>tcp</code>.</div>
  </div>
</div>

<Accordion title="Example">

```ruby
sandbox = Microsandbox::Sandbox.create("api", image: "python", ports: { 8080 => 80 })

sandbox = Microsandbox::Sandbox.create(
  "dns",
  image: "alpine",
  ports: [
    { host_port: 8080, guest_port: 80, bind: "0.0.0.0" },
    { host_port: 5353, guest_port: 53, protocol: "udp" }
  ]
)
```

</Accordion>

### secrets

An array of hashes. Each entry requires all three string fields below. Ruby does not expose per-location substitution, violation-action, or passthrough-policy configuration.

<p className="msb-label">Fields</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>env</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">Guest environment variable receiving the secret placeholder.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>value</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">Secret value to substitute into permitted requests.</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>allowed_host</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">Destination host allowed to receive the secret.</div>
  </div>
</div>

<Accordion title="Example">

```ruby
sandbox = Microsandbox::Sandbox.create(
  "worker",
  image: "alpine",
  secrets: [{ env: "API_TOKEN", value: ENV.fetch("API_TOKEN"), allowed_host: "api.example.com" }]
)
```

</Accordion>

### proxy

Accepts an `OutboundProxy`. The same object can be passed to `builder.proxy(proxy)`.

## Rule

These helpers return rule hashes for the `rules` field of [network](#network).

#### <span className="msb-recv">Microsandbox::Rule.</span><span className="msb-hn">allow()</span>

```ruby
Microsandbox::Rule.allow(direction: :egress, protocol: nil, port: nil, destination: nil) # => Hash
```

Build an allow rule. Omitted fields match everything.

#### <span className="msb-recv">Microsandbox::Rule.</span><span className="msb-hn">deny()</span>

```ruby
Microsandbox::Rule.deny(direction: :egress, protocol: nil, port: nil, destination: nil) # => Hash
```

Build a deny rule. Omitted fields match everything.

#### <span className="msb-recv">Microsandbox::Rule.</span><span className="msb-hn">allow_dns()</span>

```ruby
Microsandbox::Rule.allow_dns # => Array<Hash>
```

Allow plain DNS to the sandbox gateway. Returns a UDP/53 rule and a TCP/53 rule for the `host` group; splat them into `rules`. DoT (TCP/853) is not included.

<Accordion title="Example">

```ruby
sandbox = Microsandbox::Sandbox.create(
  "worker",
  image: "alpine",
  network: {
    rules: [
      *Microsandbox::Rule.allow_dns,
      Microsandbox::Rule.allow(destination: Microsandbox::Destination.group(:public), protocol: :tcp, port: 443)
    ]
  }
)
```

</Accordion>

#### <span className="msb-recv">Microsandbox::Rule.</span><span className="msb-hn">deny_dns()</span>

```ruby
Microsandbox::Rule.deny_dns # => Array<Hash>
```

Deny gateway UDP/53 and TCP/53.

## Destination

These helpers return destination hashes of the form `{ kind:, value: }`. Unlike a shorthand String, they are never reinterpreted, so `Destination.cidr("example.com")` fails instead of becoming a domain rule.

#### <span className="msb-recv">Microsandbox::Destination.</span><span className="msb-hn">any()</span>

```ruby
Microsandbox::Destination.any # => Hash
```

Match any destination.

#### <span className="msb-recv">Microsandbox::Destination.</span><span className="msb-hn">ip()</span>

```ruby
Microsandbox::Destination.ip(ip) # => Hash
```

Match one IPv4 or IPv6 address.

#### <span className="msb-recv">Microsandbox::Destination.</span><span className="msb-hn">cidr()</span>

```ruby
Microsandbox::Destination.cidr(cidr) # => Hash
```

Match a CIDR range, such as `172.28.0.0/16`.

#### <span className="msb-recv">Microsandbox::Destination.</span><span className="msb-hn">domain()</span>

```ruby
Microsandbox::Destination.domain(domain) # => Hash
```

Match one domain exactly.

#### <span className="msb-recv">Microsandbox::Destination.</span><span className="msb-hn">domain_suffix()</span>

```ruby
Microsandbox::Destination.domain_suffix(suffix) # => Hash
```

Match a domain and all of its subdomains. `domain_suffix("github.com")` matches `github.com` and `api.github.com`. A single label such as `com` is rejected. Use this instead of a `*.github.com` pattern, which is read as a literal name.

#### <span className="msb-recv">Microsandbox::Destination.</span><span className="msb-hn">group()</span>

```ruby
Microsandbox::Destination.group(group) # => Hash
```

Match an address group.

<p className="msb-label">Parameters</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>group</code><span className="msb-type">String | Symbol</span></div>
    <div className="msb-param-desc"><code>public</code>, <code>private</code>, <code>loopback</code>, <code>link-local</code> (or <code>link_local</code>), <code>metadata</code>, <code>multicast</code>, or <code>host</code>. <code>host</code> is the host machine as <code>host.microsandbox.internal</code>; <code>loopback</code> is the sandbox's own <code>127.0.0.1</code>.</div>
  </div>
</div>
